Random Walk

A turquoise point takes random steps across a gray square canvas, leaving a persistent trail. Change its color or step range while it moves, and click the canvas to clear the marks.

Walk settings
  • Canvas mouse action: click the canvas to clear the trail. While the mouse button is held down, drawing and movement pause.
  • Keyboard shortcuts: none. Use Tab to reach the controls; arrow keys adjust the slider, the color picker uses its native controls, and Enter or Space activates the page buttons.
  • Trail color: changes the walker's color immediately.
  • Maximum step distance (0–10 px per axis): changes the range of each independently randomized horizontal and vertical step immediately. The default of 5 preserves the original range.
  • Restart Simulation: clears the canvas and returns the walker to its starting point and direction, keeping the current settings.
  • Reset Everything: restores the sketch defaults and restarts the simulation.
