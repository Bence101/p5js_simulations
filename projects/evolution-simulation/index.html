Creature Obstacle-Avoidance Prototype

An early p5.js prototype for creatures navigating a bounded board with rectangular obstacles. Creatures start at random positions and velocities and use a single forward ray for obstacle detection and avoidance; evolution, learning, and multi-ray vision are not implemented.

Simulation settings
  • Arrow keys: steer the first creature left or right and increase or decrease its speed. Q stops it.
  • R: restore the view. F: fit the board. + and - change simulation speed.
  • Space: pause or resume the p5 draw loop. *: fast-forward by 1,000 simulation steps. S: update the board JSON output below.
  • Left mouse button: drag from the top-left toward the bottom-right to add a rectangular obstacle; double-click an obstacle to remove it.
  • Middle mouse button: drag to pan. Mouse wheel: zoom. While any mouse button is held, all creatures seek the pointer.
  • While paused, the draw loop stops, so creature movement, board editing, panning, and zooming resume only after the loop is restarted.
  • Creature count: 1–20 creatures; this setting applies on restart. The interface caps the count at 20 to keep this prototype responsive.
  • Sight distance: sets the single ray's length and the avoidance look-ahead distance; it applies live.
  • Field-of-view arc half-angle: adjusts the displayed arc only. It does not change obstacle perception, which still uses one forward ray; it applies live.
  • Draw ray / field-of-view arc: toggles the ray and visual arc independently; both apply live.
  • Debug overlays: show obstacle-avoidance guides and obstacle-side triangles; both apply live.
  • Restart Simulation: recreates the creatures using current settings and preserves user-created obstacles, the view, simulation speed, and pause state.
  • Reset Everything: restores the settings defaults, removes user-created obstacles, restores the initial view and simulation speed, and resumes the draw loop.
  • Expand the current single ray to 5–7 eyesight rays, then explore population-based genetic algorithms and a compatible NEAT component. An initial experiment proposed in the notes is to test creatures moving toward the board center. See the original planning notes, lines 2–7.
