Ant Pheromone

Ants wander through a fixed map, collect food, and return it to their anthill while leaving distinct wander and return pheromones. Explore the existing discrete foraging simulation, its obstacle behavior, and the effect of pheromone visibility without changing its model.

Simulation controls

Use a whole number of 0 or greater. Speed changes apply live; 0 pauses simulation updates while the page and canvas remain usable.

Speed is uncapped and counts updates, not guaranteed wall-clock acceleration. High speeds, additional ants, and many pheromones increase computational cost.

This checkbox changes pheromone rendering only. Pheromone creation, sensing, following, and lifetime updates continue while marks are hidden.

Actions and shortcuts

  • Focus the canvas with Tab or by clicking it. The A, D, and R shortcuts work only while the simulation canvas has keyboard focus; they do not run from form controls or buttons, and Ctrl/Cmd browser shortcuts are left alone.
  • D increases speed by 1 while the current speed is 4 or less; above 4 it increases speed by 10. For example, the sequence can be 4, 5, 15, 25.
  • A decreases speed by 10, with the original lower bound of 0.
  • R requests the original fast-forward by setting the skipped-update counter to 15 minus 1000. At speed 1 that means 1000 compensated updates plus one ordinary update in the same draw callback. At speed 0 it stays pending until updates resume. A large loop can temporarily monopolize a draw callback; R is not Restart Simulation.
  • Click inside the canvas to add one food pile containing 30 units at the pointer position. Clicks outside the canvas do not add food. A touch tap is supported as a single canvas click; dragging does not paint food.
  • Hover over an ant to show its existing tracing and inspection overlay. The overlay includes its current purpose, pheromone count, time since seeing the anthill, and obstacle-avoidance state.

Controls and simulation actions

  • Simulation speed: an integer number of updates per rendered frame, applied live with no maximum. A value of 0 pauses model updates, but rendering and page controls remain available. The first 15 updates are compensated as warm-up; with speed 1, the first draw callback therefore also runs one ordinary update (16 updates total). If speed is 0, the warm-up waits until updates resume.
  • Show pheromones: toggles only the drawing of pheromone marks; it does not disable pheromone behavior or aging.
  • Restart Simulation: creates a fresh world using the current controls, including a speed of 0. It discards accumulated entities and counters without changing the controls.
  • Reset Everything: restores the configuration-derived control defaults and creates a fresh default world. The native form reset has the same effect.

The fixed canvas scales down uniformly to fit. p5.js maps pointer coordinates back to the original logical canvas when displayed smaller.
