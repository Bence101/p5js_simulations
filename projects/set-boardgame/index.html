Set Boardgame

Find matching patterns in a randomly generated board of cards. Play by selecting cards yourself, or use the built-in solver to reveal a valid set.

Goal: select three cards whose color, shading, and symbol pattern are each either all the same or all different.

Loading the board. Game controls stay disabled until initialization succeeds.

Game actions
  • Click a card: select or deselect up to three cards. A valid trio has the same value on all three cards or a different value on every card for each feature. Valid sets are confirmed and deselected automatically. If a trio is invalid, click one selected card to remove it before trying another combination.
  • Find a Set: the solver checks the current board and outlines one valid trio in green. Select those cards to submit the set. If none exists, the status message recommends starting a new board.
  • Restart Game: deals 12 new random cards and clears selections and solver highlights.
  • Reset Everything: deals a new board too; there are no editable settings to restore.
  • Mouse: clicking empty canvas space has no effect. Card selection is mouse-only and has no keyboard equivalent.
  • Keyboard: there are no custom shortcuts. Use Tab to reach the game actions and Enter or Space to activate them; the shared restart and reset buttons work the same way.

Card features: the board has 12 randomly generated cards. Each card has a color, a shading (outline, solid, or pale), and a symbol pattern. Shape and number of symbols combine as one feature. Some boards may not contain a set, so use the solver to check before restarting.
