Particle Life

Explore six groups of particles that attract or repel one another according to a full, directional interaction matrix. Change every interaction live, randomize the rules, or create and delete cells with a configurable mouse brush.

Interactions and mouse brush

Interaction matrix

Rows are the affected cells; columns are their neighbors. Every entry is independent, including the diagonal. Values run from -1 (repulsion) to +1 (attraction); very close cells still repel.

Focus an entry and use +, -, or arrow keys to change it by 0.1. On narrow screens, scroll this table sideways to reach all six columns.

All 36 directed interactions: row affected by column

Group numbers preserve the original order. Legacy names and colors are retained: group 5 is called Purple but its particles are cyan; group 6 is called Orange but its particles are magenta. Their original matrix markers are magenta and cyan, respectively.

Mouse brush and cells

Affects only cells created by the mouse. Random chooses a group independently for each new cell.

Mouse mode

Replaces the current population with 100 random cells, without changing any settings.

  • Actions and shortcuts: press inside the canvas to create or delete cells. Focus a matrix slider and press + or - to adjust it by 0.1; its arrow keys also adjust by 0.1. There are no other custom simulation shortcuts and no keyboard equivalent for canvas creation or deletion.
  • Interaction matrix: all six rows and six columns are editable, including same-group interactions on the diagonal. Row A, column B controls how cells in group A respond to nearby cells in group B; the reverse entry is separate. Positive values attract, negative values repel, and zero removes this attraction/repulsion component. The existing short-range repulsion remains even at zero or positive values. Changes apply immediately without replacing particles.
  • Matrix values and colors: values range from -1 to +1 and display two decimal places; the simulation uses the slider's numeric precision, not the rounded display. The red-to-green marker indicates the value, not the particle group. Numbered row/column headers identify groups without relying on color. Groups 5 and 6 retain the legacy name/color differences explained below the table.
  • Regenerate Matrix: immediately randomizes every entry, including the diagonal, while retaining all particles and brush settings. Initially only the off-diagonal entries are random; the diagonal starts at +1.
  • New-cell color: selects one of the six groups for subsequent mouse-created cells. Random selects a group for each cell. It does not recolor existing cells or affect regenerated populations.
  • Cells per mouse press (1–30): immediately sets the number of cells added by each creation press; the default is 10. It does not limit the total population or affect deletion.
  • Brush radius (0–100 logical px): immediately sets the creation/deletion circle, default 50. It scales visually with the fixed canvas. A zero radius creates cells at the press position and deletes none.
  • Mouse mode: Create cells (the default) adds cells at random positions within the brush radius. Delete cells removes all cells strictly inside that radius, regardless of color or the cells-per-press setting. Presses must be strictly inside the canvas; continuous drag painting is not implemented.
  • Canvas touch limitation: the preserved p5.js 1.4.0 touch handling can deliver both a touch fallback and a compatibility mouse event for one tap, creating cells twice. Use a mouse for predictable cells-per-press behavior. The native HTML controls, including matrix sliders, support touch independently of this legacy canvas behavior.
  • Regenerate All Cells: replaces the population with 100 randomly positioned cells in random groups, retaining the entire matrix and every brush control. It does not use the brush count or selected color.
  • Restart Simulation: also starts a fresh population of 100 random cells, retaining every current control value, including all 36 matrix entries. Changes to the matrix and brush settings are live; no setting requires a restart.
  • Reset Everything: restores Random color, 10 cells per press, a 50 px radius, Create mode, and the initial matrix for this page visit (diagonal +1 and the original random off-diagonal values), then restarts with 100 random cells. It does not reload the page.
  • Canvas and information: the logical canvas stays 1000×600 and scales down uniformly on smaller screens without changing the physics. Cells wrap at its edges. The overlay displays FPS and the current number of cells.
  • Native keyboard controls: use Tab/Shift+Tab to move through controls, arrow keys for sliders and radio options, and Enter/Space for buttons. The select uses your browser's native keyboard controls. The matrix's scroll region is focusable; scroll it horizontally to access all columns on narrow screens.
