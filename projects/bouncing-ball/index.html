Bouncing Ball

Watch balls bounce off the canvas edges and optionally collide with one another. Adjust their appearance as they move, restart with a chosen ball count, or click the canvas to add and remove balls.

Controls

Ball settings

Applies on restart. Canvas clicks can change the current number without changing this setting.

Simulation not connected. Controls stay disabled until initialization succeeds.

How to Use

  • Ball color: changes all current balls immediately using the native color picker.
  • Number of balls (1–10): chooses how many balls the next restart creates; changing it does not replace the current balls.
  • Ball diameter (12–72 px): changes all current balls immediately. Balls are constrained to the canvas; the drawn diameter is capped if the canvas is smaller than the selected size.
  • Ball collisions: immediately turns ball-to-ball bouncing on or off. Balls always bounce off the canvas edges.
  • Restart Simulation: replaces the current balls with the selected count, retaining all control values.
  • Reset Everything: restores the default color, one ball, 36 px diameter, and collisions off, then restarts the simulation.
  • Canvas clicks: click an empty spot to add a ball, up to 10 total; click a ball to remove it. When balls overlap, the topmost one is removed. Clicks do not change the count slider.
  • Keyboard: use Tab and Shift+Tab to move between controls, arrow keys to adjust sliders, Space to toggle collisions, and Enter or Space to activate buttons. The color picker uses your browser's native keyboard controls.
  • Custom simulation shortcuts: none. Canvas add/remove actions use the mouse; no additional canvas keyboard controls are implemented.
