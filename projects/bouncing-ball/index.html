Bouncing Ball

How to Use

Choose a color or diameter to update all current balls immediately. Set the number of balls, then select Restart Simulation to replace the current set with that many balls; the selected controls are retained. Turn on Ball collisions to make balls bounce off one another. Balls always bounce off the canvas edges.

Click an empty spot in the canvas to add a ball, up to 10 total. Click a ball to remove it. If balls overlap, the topmost one is removed.
