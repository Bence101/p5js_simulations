Bouncing Ball

A translucent turquoise ball moves across a gray square canvas, leaving marks as it travels. Its original step-based movement, edge checks, and click-to-clear behavior are preserved, with optional controls for appearance and motion.

Ball settings
  • Ball color: changes the RGB color immediately. The ball remains translucent, as in the original.
  • Speed multiplier (0.25–3×): scales the original 10 px horizontal and 20 px vertical steps per frame. The default 1× retains the original speed at 60 frames per second.
  • Diameter (8–60 px): changes the ball size immediately. The default is the original 20 px.
  • Leave motion trail: when enabled, marks persist until the canvas is cleared; when disabled, the background is redrawn each frame.
  • Restart Simulation: clears the canvas and returns the ball to its original starting point and direction, keeping current settings.
  • Reset Everything: restores the sketch defaults and restarts the simulation.
  • Canvas mouse action: clicking clears the canvas. While the mouse button is held down, drawing and movement pause; there are no custom keyboard shortcuts.
  • Keyboard: use Tab to reach controls; arrow keys adjust sliders, use the native color picker and Space for the checkbox, and Enter or Space for buttons.
