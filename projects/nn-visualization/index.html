Training is running.

  • Keyboard: there are no custom keyboard shortcuts. Use Tab to move through the controls, arrow keys to adjust sliders, and Enter or Space to activate buttons.
  • Canvas: there are no custom canvas mouse controls.
  • Setting application: the toggle switches between immediate changes and changes held until Restart Simulation. In immediate mode, training updates, learning rate, and pause threshold apply live; changing the dataset or architecture creates a fresh network immediately, and changing the dataset also generates new samples and a decision grid.
  • Dataset: choose Same-sign quadrants, Double spiral, or Circle (inside/outside radius 5). Each problem has two inputs and one output.
  • Training updates per frame: choose how many randomly sampled training examples are learned on each frame (1–500).
  • Learning rate: choose the network's learning rate (0.001–0.1).
  • Hidden layers: set up to five hidden layers with 0–9 nodes each. A value of 0 omits that layer; input and output layer sizes are selected by the dataset.
  • Pause at accuracy: training pauses when accuracy reaches the entered percentage (1–100). Resume Training continues the current network; automatic pausing re-arms after accuracy falls below the threshold.
  • Restart Simulation: applies staged settings, creates fresh random network weights and biases, and resets the learning-iteration count. It retains the current data and grid unless the selected dataset changed; the accuracy threshold can pause the new run again once it is reached.
  • Reset Everything: restores all control defaults defined by the sketch and restarts with a fresh network.

The canvas places the selected dataset's decision surface beside the network graph and reports FPS, learning iterations, and training-set accuracy.
