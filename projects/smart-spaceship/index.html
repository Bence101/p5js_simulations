Smart Spaceship

A population of colored ships searches for the green target by evolving movement genes over generations. Successful routes are favored through fitness-weighted selection, crossover, and mutation; gray obstacles can be edited directly on the canvas.

Simulation settings

0 pauses progress; 1 is the original speed. Higher values run more population updates per rendered frame.

  • Canvas clicks: click two points to add a rectangular obstacle between them. Both sides must be at least 5 pixels long.
  • Canvas double-click: remove the obstacle under the pointer.
  • Simulation speed: changes population updates per frame immediately; 0 pauses progress and the original default is 1.
  • Reset speed: restores only the speed setting to its default without restarting the simulation.
  • Skip to Next Generation: fast-forwards the remaining updates of the current generation until the next generation begins.
  • Restart Simulation: starts a fresh population at generation 0, clears the chart, and restores the original obstacle course while keeping the current speed setting.
  • Reset Everything: restores the sketch's default speed and restarts the simulation.
  • Keyboard: there are no custom keyboard shortcuts. The native controls work with standard keyboard navigation and activation.
