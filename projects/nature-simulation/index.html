Nature Simulator

Explore a small ecosystem of autonomous agents that wander, forage for grass, reproduce when healthy, and disappear as their health runs down. Grass reappears over time, while a live chart tracks agent and grass counts. The simulation keeps its original 600 by 400 logical canvas and behavior.

Population settings
  • Keyboard: there are no custom simulation shortcuts. Use Tab or Shift+Tab to reach controls; the native sliders respond to arrow keys, and buttons activate with Enter or Space.
  • Mouse: the simulation canvas has no mouse controls. Hover over chart points to inspect Chart.js tooltips; this chart interaction has no keyboard equivalent.
  • Initial agents: choose 0-200 starting agents (default 100). This setting takes effect when the simulation is restarted.
  • Initial grass: choose 0-200 starting grass patches (default 50). This setting takes effect when the simulation is restarted.
  • Grass spawn interval: choose 1-120 frames between new grass patches (default 10). Changes apply live while the simulation runs.
  • Restart Simulation: clears the population chart and starts a new simulation using the current settings without changing the controls.
  • Reset Everything: restores the sketch defaults, updates all slider outputs, clears the chart, and starts a new simulation.

The population chart samples agent and grass counts every 60 simulation frames.
